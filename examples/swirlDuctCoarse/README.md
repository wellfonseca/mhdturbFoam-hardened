# swirlDuctCoarse — integration test (not a verification case)

A coarse swirl case in a 60-sided polygonal duct, used as a **smoke test** for
the code paths that the analytical Hartmann cases in `cases/` do not cover.
It has **no exact solution** and must not be cited as verification.

## What it exercises

| aspect | `cases/channelHartmann*` | `examples/swirlDuctCoarse` |
|---|---|---|
| turbulence model | laminar | **k-omega SST** (`turbulence->divDevReff`) |
| applied field `B` | transverse or spanwise | **spanwise `(0 0 -10)`** |
| inlet | uniform `(1 0 0)` | **`swirlFlowRateInletVelocity`**, 0.5 m3/s at 100 rpm |
| geometry | Cartesian channel | **60-sided polygonal duct** (STL + snappyHexMesh) |
| patches | inlet/outlet/walls | inlet/outlet/`wall` |
| purpose | verification against exact solution | integration / divergence check |

This matters because the solver exists to be turbulent: a bug in the
`divDevReff` + RAS path, or an instability specific to the swirl inlet, would
not be caught by the laminar verification cases.

## Geometry and settings

| item | value |
|---|---|
| duct | 60-sided polygon, length 2.5 m, R = 0.0762 m (6 in) |
| mesh | **generated by `Allrun`**: `blockMesh` (64x12x12 background) + `surfaceFeatureExtract` + `snappyHexMesh` |
| cells after snappy | 6144 |
| fluid | rho = 1000 kg/m3, nu = 4.1792e-4 m2/s, sigma = 70.9 S/m, mu = 1.2566e-6 H/m |
| turbulence | k-omega SST |
| field | `B = (0 0 -10)` uniform |
| time | 250 steps, dt = 2e-5 s (t = 5e-3 s) |
| runtime | ~30 s, serial |

The mesh is **regenerated, never committed**: the package tracks the generator
(`system/blockMeshDict`, `system/snappyHexMeshDict`,
`system/surfaceFeatureExtractDict`) and the surface
(`constant/triSurface/poligono.stl`, 78 kB), not the ~1 MB `polyMesh`.

## Run

```bash
source /path/to/OpenFOAM-6/etc/bashrc
./Allrun      # serial, ~30 s
./Allclean    # removes mesh, times, postProcessing and logs
```

## Expected result

```
cells:            6144
250 time steps, log ends with "End"
max continuity error            ~1.5e-15
max magnetic flux divergence    ~1.5e-18
```

## Deliberate simplifications

* **Short physical time.** 5e-3 s is not a developed swirl; the case only
  checks that the solver advances without floating-point exceptions.
* **Coarse mesh.** ~11 cells across the duct. Fine enough for a divergence
  check, far too coarse for quantitative results.
* **Serial.** The production study of the polygon duct uses 480 000 cells,
  32 subdomains, dt = 2e-5 s and 100 000 steps to t = 2 s; that
  configuration does not belong in this repository (see the production study
  package).
* **No magnetic patches.** The production cases add `magnet_*` patches; here
  the field is uniform over the whole domain.
